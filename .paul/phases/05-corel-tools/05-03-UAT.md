## Checklist

1. Flyout toolbox
   - The toolbox shows an Artistic Media button (taper-stroke icon) with a
     flyout triangle as the face of the Artistic media group.
   - The flyout contains Artistic Media, Calligraphic and Spray; picking
     Calligraphic or Spray switches to those upstream tools and their bars.
   - `[ ]` pass `[ ]` fail

2. Keys and Tools menu
   - Key `I` (and `Shift+I`) selects the Artistic Media tool.
   - Tools ▸ Artistic Media Tool switches to the tool and shows its controls
     bar.
   - `[ ]` pass `[ ]` fail

3. Preset mode
   - Draw a freehand stroke with each of the 7 presets (Uniform, Taper End,
     Taper Start, Taper Both, Lens, Teardrop, Swell): each becomes ONE filled
     object in the tool colour (fill = the color set for the tool, black by
     default).
   - Smoothing 0 produces a polyline skeleton (more nodes, sharp turns);
     smoothing 100 produces a smooth curve skeleton with few nodes (check with
     the Node tool or status bar).
   - `[ ]` pass `[ ]` fail

4. Brush mode
   - Draw a stroke with each of the 4 brushes (Dry Brush, Split Stroke,
     Stipple, Bristle): gaps between the parts are visible, and Bristle shows
     a hole along its middle.
   - `[ ]` pass `[ ]` fail

5. Calligraphic mode
   - With Calligraphic selected, drag in different directions: the stroke is
     thick across the nib and thin along it, ends are flat (nib-shaped), and
     angle 0° / 45° / 90° clearly differ; the Shape dropdown is insensitive.
   - `[ ]` pass `[ ]` fail

6. Live skeleton editing
   - With the Node tool, drag nodes of a stroke's skeleton: the brush follows
     the skeleton live while dragging.
   - `[ ]` pass `[ ]` fail

7. Property bar edits (stroke selected)
   - With strokes selected, each control changes them in one undo step per
     change: mode (Preset/Brush/Calligraphic), shape, width, and the
     "Scale stroke with object" toggle.
   - Smoothing does NOT change existing strokes (creation-only); it only
     stores the value for the next stroke.
   - Selecting an existing stroke shows its mode, shape, width and angle in
     the bar.
   - `[ ]` pass `[ ]` fail

8. Convert a plain path
   - Select a plain stroked path and pick a preset on the bar (e.g. change the
     shape with Preset mode active): the path becomes a live artistic stroke
     filled with its former stroke colour.
   - `[ ]` pass `[ ]` fail

9. Transforms
   - Scale a stroke with the Pick tool by ×2: with "Scale stroke with object"
     on, the width doubles; with it off, the width stays.
   - Rotating a calligraphic stroke keeps the nib angle page-fixed (the thin/
     thick directions stay put relative to the page).
   - `[ ]` pass `[ ]` fail

10. Duplicates
    - Ctrl+D a stroke, change the width of the copy: the original is
      unchanged.
    - `[ ]` pass `[ ]` fail

11. Break Artistic Media Apart

      static filled path and an invisible (fill:none;stroke:none) but
      selectable skeleton sibling appears (visible in the Object Manager and
      selectable with Tab); one Ctrl+Z restores the live stroke.
    - `[ ]` pass `[ ]` fail

12. Save, reload, export

    - `[ ]` pass `[ ]` fail

13. Cancel, click-select and responsiveness

    - `[ ]` pass `[ ]` fail
