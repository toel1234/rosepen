<objective>
Give Rosepen CorelDRAW's Artistic Media tool: the user drags a freehand stroke (or picks an existing path) and gets a filled brush object along it — a Preset stroke shape (taper, lens, teardrop, swell…), a Brush stroke (multi-part textured shapes with gaps and holes) or a Calligraphic stroke drawn by a flat nib held at a fixed angle. The brush stays LIVE-LINKED to its skeleton path: editing the skeleton with the Node tool, transforming it, or changing width / shape / mode / nib angle afterwards on the property bar re-renders the brush. "Break Artistic Media Apart" freezes it into a static outline plus the bare skeleton.

Purpose: Phase 5 adds Corel-only tools. Upstream (pinned 3d6e954a) has the pieces but not the object: the Calligraphic tool draws STATIC paths (no skeleton, nothing editable afterwards), Pattern Along Path / Taper Stroke / Power Stroke each cover one look with incompatible parameter models, and the only angle-nib LPE (Dynastroke) is a hidden experimental normal-offset approximation. This plan adds ONE small LPE whose skeleton is the path's own `inkscape:original-d` (so the live link is native: Node tool, transforms, duplicate, undo, save/reload all work through upstream LPE machinery), a pure gtest-locked geometry/library model, CLI-reachable actions (single source of truth, also used by the tool and toolbar), and an Artistic Media tool as the face of the existing 04-01 artistic-media flyout (Calligraphic and Spray stay inside it as Corel's Expression and Sprayer stand-ins).

Output: `artistic-media-geometry` + `artistic-media-library` (gtest), `LPEArtisticMedia` + `app.artistic-add|apply|set|list|break|library` (document gtest + headless CLI corpus with SVG/PNG[/PDF] stages incl. live skeleton edit, mode switch, break-apart freeze and load-time repair/fallback), the interactive Artistic Media tool with property-bar toolbar, flyout/menu/key wiring, and a manual UAT for the interactive parts.
</objective>

Design decisions (planner, from the evidence above):
- ONE NEW LPE ON THE SKELETON PATH, not a group and not a new SP object. An artistic media object is a single `svg:path` with `class="rosepen-artistic"` whose `inkscape:original-d` IS the skeleton and whose `d` is the LPE output (the filled brush outline, `stroke:none`). Why: the Node tool already edits `original-d` of LPE paths and shows the result live; transforms reach the effect through `transform_multiply`; duplicate forks effects; undo/save/reload are upstream LPE behaviour; the output is a plain filled path, so PNG/PDF/PDF-X export needs zero pipeline change and other SVG viewers see the brush. A group (05-02 style) would only be needed for multi-colour brushes (deferred) and would re-introduce the sibling-sync machinery 05-02 had to harden. Rejected: switching between three upstream LPEs per mode (mode change on the property bar would swap effect objects, break undo granularity and ids, and upstream has no exact flat-nib LPE); a new SPObject (src/object + renderer + export work, invisible elsewhere).
- Objects are found STRUCTURALLY: an SPPath whose effect stack contains an effect of type ARTISTIC_MEDIA (the class is a styling/scripting hint, also written, never required); never via id lists. Discovery walks the whole document in document order (layers, groups, PowerClip contents, master layers).
- LPE `LPEArtisticMedia final : Effect`, key `artistic_media`, label `NC_("path effect", "Artistic Media")`, icon `taper-stroke`, description `N_("Live brush stroke drawn along the path: preset shapes, brush strokes or a calligraphic nib")`, `LPECategory::Convert`, on_path true, on_shape/group/image/text false, experimental TRUE (hidden from the gallery; entry points are the tool, the toolbar and `app.artistic-*`). Parameters: `mode` EnumParam {`preset`, `brush`, `calligraphic`} (default preset); `shape` TextParam (library name of the preset/brush; ignored by calligraphic; default `lens`); `width` ScalarParam (mm in the path's LOCAL user space, default 10, range (0, 1000]); `angle` ScalarParam (degrees, nib angle, default 30, stored normalised to [0, 180)); `scale_with_object` BoolParam (default true); `shape_d` HiddenParam (embedded unit-space shape data, see repair below).
- Unit-space shape model (Preset and Brush share it): a shape is a closed path in u ∈ [0, 1] (along the skeleton, u = 0 at its start) × v ∈ [−0.5, 0.5] (across). Mapping per skeleton subpath of arc length L with width W (uu): P(u, v) = S(u·L) + v·W·N(u·L), S arc-length parametrised, N = rot90(unit tangent) — for travel towards +x in SVG's y-down space N = (0, +1), so v > 0 is the +y side. Shapes are NOT renormalised by their bounds (u, v are absolute), every library shape spans u 0..1 and v −0.5..0.5, so W is exactly the stroke's maximum width and the area on a straight skeleton is `area_fraction × L × W`. Outer subpaths have positive shoelace area in (u, v) (the orientation of `M 0,-0.5 L 1,-0.5 L 1,0.5 L 0,0.5 Z`), holes negative; output fill-rule nonzero. Each skeleton subpath gets one full copy of the shape (closed skeletons: u runs once around).

- Calligraphic = exact sweep of a flat nib (segment of length W, direction d = (cos θ, −sin θ) in the path's coordinates, i.e. θ counter-clockwise on screen) along each skeleton subpath. Algorithm (no boolean ops): split every curve at the parameters where cross(C′(t), d) = 0 (rotate the curve so d maps to +x, take `toSBasis()`, roots of the derivative of the y component in (0, 1), dedupe within 1e-9; lines need no split); drop pieces whose |cross| ≤ 1e-12·|C′| everywhere (parallel to the nib: zero-area sweep); group consecutive pieces with the same cross sign into runs; each run R gives the closed polygon-path `R + (W/2)d` forward, line, `R − (W/2)d` reversed, close; runs with negative sign are reversed so every run polygon has the same orientation. Why exact: on a run the map (t, s) ↦ C(t) + s·d has a Jacobian det[C′, d] of constant sign, so the run polygon is the oriented image of a rectangle boundary and every covered point has winding of ONE sign; with fill-rule nonzero the union of run polygons is exactly the swept region (no holes, no boolean step). Translation keeps Béziers exact, so curves stay curves. Ends are flat (nib-shaped), as a real broad pen. θ and θ+180° are the same nib (stored normalised to [0, 180)). θ is PAGE-fixed: transforms never change it.
