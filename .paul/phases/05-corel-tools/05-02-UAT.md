# 05-02 Manual UAT — Dimension tool, live dimensions and the controls bar

Status: **OWED** (not run). The dimension model, the live path effect, the
`app.dimension-*` actions and the headless corpus are machine-locked
(`test_dimension-geometry`, `test_dimension-lpe`, 9 `cli_dimension-*` scenarios
covering SVG, PNG and PDF). The interactive checks below need a deliberate GUI
session.

Environment note: `DISPLAY=:0` / `WAYLAND_DISPLAY=wayland-0` exist on the host
but belong to the live GNOME session; `Xvfb` is absent. Launch deliberately:
`build/bin/rosepen` (or `install/bin/rosepen` after `ninja install`).

## Checklist

1. Flyout toolbox
   - The toolbox shows a single Dimension button with a flyout triangle as the
     face of the Dimension group.
   - The flyout contains Dimension, Measure and Connector; picking Measure
     switches to the upstream Measure tool and its toolbar.
   - `[ ]` pass `[ ]` fail

2. Tools menu
   - Tools ▸ Dimension Tool switches to the Dimension tool and shows its
     controls bar.
   - The item disappears/no-ops for tools that do not exist (there is no
     separate key binding, as in the reference).
   - `[ ]` pass `[ ]` fail

3. Auto mode
   - Drag mostly horizontally between two points: a horizontal dimension is
     created (label shows the distance, e.g. `50.00 mm`).
   - Drag mostly vertically: a vertical dimension.
   - Move the mouse after the drag and click to set the offset; the dimension
     line follows the pointer before the click.
   - `[ ]` pass `[ ]` fail

4. Parallel mode
   - Drag between two points: an aligned dimension parallel to the drag.
   - Hold Shift while picking the second point: the angle snaps to 15° steps.
   - `[ ]` pass `[ ]` fail

5. Angular mode
   - Click the vertex, then arm A, then arm B; move to set the arc radius and
     click to place. The label shows the angle in degrees with `°`.
   - `[ ]` pass `[ ]` fail

6. Segment mode
   - Click a path segment: a dimension appears along that segment (chord).
   - Clicking empty canvas or a non-path object shows the "No path segment"
     message and creates nothing.
   - `[ ]` pass `[ ]` fail

7. Snapping and anchors
   - With snapping on, the picked points snap to nodes and bounding-box
     handles/centres (the free point follows the object).
   - Moving the measured object moves the dimension; scaling it updates the
     value and keeps the anchor on the same handle.
   - `[ ]` pass `[ ]` fail

8. Live update and freeze
   - Move, scale or node-edit a measured object: the value and geometry update
     live without reselecting the dimension.
   - Delete a measured object: the dimension freezes at its last value instead
     of collapsing.
   - `[ ]` pass `[ ]` fail

9. Controls bar
   - Mode buttons switch the creation mode for the next dimension.
   - Precision, Offset, Units (unit picker), Label (Above/Inline/Below) and
     Show units each change the defaults for new dimensions AND update every
     selected dimension (one undo step per change).
   - `[ ]` pass `[ ]` fail

10. Label behaviour
    - Drag right-to-left or bottom-to-top: the label stays upright.
    - "Inline" puts the label on the line; "Below" between line and geometry;
      "Above" beyond the line.
    - `[ ]` pass `[ ]` fail

11. Undo/redo and persistence
    - Ctrl+Z after creating a dimension removes it completely; Ctrl+Shift+Z
      restores it.
    - Save and reopen: dimensions are still live and still follow their
      measured objects.
    - Copy/paste or duplicate a dimension: both copies stay linked to their own
      measured objects and labels do not cross-wire.
    - `[ ]` pass `[ ]` fail

12. Pages and master layers
    - Place a dimension on page 2: it renders on canvas and in the PDF/PDF-X
      export.
    - Put a dimension in a master layer: it renders on every page.
    - `[ ]` pass `[ ]` fail

13. Cancel and cleanup
    - Esc during creation cancels and removes the preview without touching the
      document.
    - Switching tools mid-creation removes the preview items.
    - `[ ]` pass `[ ]` fail

14. Object Manager
    - Selecting a dimension shows "Dimension" in the Object Manager (it is a
      group with the `rosepen-dimension` class).
    - `[ ]` pass `[ ]` fail
