# Rosepen icon theme

Toolbox and standard-bar icons for the Rosepen workspace. Each SVG overrides
the Inkscape icon of the same name; everything else falls back to
`multicolor`.

The drawings are rendered from TraceDraw's `apps/tracedraw/src/ui/icons.rs`
(https://github.com/igtoth/tracedraw, Copyright (c) 2026 Ighor Toth and the
TraceDraw contributors), used under its MIT license, see
`LICENSE-TraceDraw-MIT`. Regenerate with
`fork/tools/tracedraw-icons/generate.sh`; do not edit the SVGs by hand.
